# TehranOfflineNavigator

پروژهٔ مستقل اندروید برای مسیریابی تهران و حومه.

## وضعیت فعلی
این مخزن اسکلت اولیهٔ اپلیکیشن و گردش‌کار ساخت APK را دارد. هنوز دادهٔ نقشهٔ آفلاین تهران و موتور محاسبهٔ مسیر در پروژه قرار نگرفته‌اند؛ بنابراین این نسخه مسیریاب آفلاین کامل نیست.

## ساخت APK
از زبانهٔ Actions، گردش‌کار `Build Android APK` را انتخاب کنید و روی `Run workflow` بزنید. پس از موفقیت، فایل `TehranOfflineNavigator-debug` را از بخش Artifacts همان اجرا دریافت کنید.

## فناوری
- Android / Java
- osmdroid برای نمایش نقشه
- GitHub Actions برای ساخت APK

برای مسیریابی کاملاً آفلاین باید دادهٔ منطقه به‌همراه موتور مسیریابی به پروژه اضافه و داخل APK یا فایل‌های نصب همراه آن بسته‌بندی شود.
