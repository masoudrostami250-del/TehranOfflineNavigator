# TehranOfflineNavigator

پروژهٔ مستقل اندروید برای مسیریابی تهران و حومه.

## وضعیت فعلی
این مخزن اسکلت اولیهٔ اپلیکیشن و گردش‌کار ساخت APK را دارد. هنوز دادهٔ نقشهٔ آفلاین تهران و موتور محاسبهٔ مسیر در پروژه قرار نگرفته‌اند؛ بنابراین این نسخه مسیریاب آفلاین کامل نیست.

## ساخت APK
از زبانهٔ Actions، گردش‌کار Build Android APK را انتخاب کنید و Run workflow را بزنید. فایل خروجی با نام TehranOfflineNavigator-v3.apk در Artifacts قرار می‌گیرد و نسخهٔ بررسی‌شده در بخش Releases با برچسب install-test-v3 منتشر می‌شود.

## وضعیت فعلی
این یک نسخهٔ آزمایشی با شناسهٔ بستهٔ تازه است تا تداخل نصب با نسخه‌های قبلی کاهش یابد. APK از نظر ساختار و امضا بررسی می‌شود. هنوز دادهٔ نقشهٔ آفلاین تهران و موتور محاسبهٔ مسیر در پروژه قرار نگرفته‌اند؛ بنابراین این نسخه مسیریاب آفلاین کامل نیست.

- GitHub Actions برای ساخت و بررسی APK
